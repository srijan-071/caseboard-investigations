# Caseboard Investigations

A web application for organizing investigation work into a structured caseboard.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui / Radix UI
- React Router
- React Query
- Vitest

## Development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run test
npm run build
```

- `npm run dev` starts the Vite development server.
- `npm run lint` checks the codebase with ESLint.
- `npm run test` runs the Vitest suite.
- `npm run build` creates a production build.

## Project direction

The goal is a focused workspace for collecting case information, navigating related evidence, and keeping investigation workflows organized without hiding the underlying data model behind a hosted builder.
